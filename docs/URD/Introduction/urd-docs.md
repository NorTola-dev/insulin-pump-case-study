# User Requirements Document (URD)
## System: Automated Insulin Pump System

### 1. User Profiles
* **Patient:** Requires continuous automated insulin delivery and safety alerts.
* **Clinician:** Requires ability to set safety thresholds and basal dosage rates.

### 2. User Requirements
* **UR-01:** System must display real-time blood glucose values on the screen.
* **UR-02:** System must issue audible and visual alarms when glucose drops below 70 mg/dL or exceeds 180 mg/dL.
* **UR-03:** System must allow manual bolus entry prior to meals.
* **UR-04:** Clinicians must be able to lock maximum daily insulin caps.
